# 이미지 상품 인식 정확도 체크리스트

비개발자용. 사진 20~30장만 모아 맞/틀을 세면 **대략적인 정확도 %**가 나옵니다.

## 준비 (5분)

1. 여행·쇼핑 사진 **20~30장** 모으기 (가능하면 종류를 섞기)
2. 각 사진의 **정답 상품명**을 미리 적기 (본인이 아는 이름 기준)
3. 앱에서 이미지 분석 돌리고 **AI가 준 상품명** 적기
4. 아래 표에 `O / X / △` 표시

### 난이도 섞기 (권장 비율)

| 유형 | 비율 | 예시 |
|------|------|------|
| 쉬움 | 40% | 패키지에 브랜드·상품명 큼 |
| 보통 | 40% | 비슷한 상품 많음, 각도 애매 |
| 어려움 | 20% | 로고만, 반사광, 비슷한 타사 제품 |

## 판정 기준

| 기호 | 의미 |
|------|------|
| **O** | 맞음 — 브랜드+상품이 실질적으로 같음 (표기만 조금 달라도 OK) |
| **△** | 부분 — 카테고리/시리즈는 맞지만 세부(맛·색·사이즈)가 틀림 |
| **X** | 틀림 — 다른 브랜드/다른 상품, 또는 `미확인`인데 알아낼 수 있었던 경우 |
| **-** | 스킵 — 정답을 본인도 모름 (정확도 계산에서 제외) |

### O로 쳐도 되는 예
- 정답: `Wpc. 멜론소다 우산` / AI: `Wpc 멜론소다 접이식 우산` → **O**
- 정답: `KitKat 말차` / AI: `네슬레 킷캣 말차` → **O**

### X인 예
- 정답: `Wpc.` / AI: `Felissimo …` → **X**
- 정답: `도쿄바나나` / AI: ` custard cake` 수준으로 다른 상품 → **X**

## 점수 계산

`-`(스킵)은 분모에서 빼세요.

```
엄격 정확도(%) = O 개수 ÷ (O + △ + X) × 100
관대 정확도(%) = (O + △) ÷ (O + △ + X) × 100
```

예시: O 18, △ 4, X 3, - 5  
→ 엄격 18/25 = **72%** / 관대 22/25 = **88%**

### 토큰 관련 (선택)

| 항목 | 값 |
|------|-----|
| 2단계(팩트체크) 돌린 장수 |  |
| 2단계 안 돌린 장수 |  |
| 2단계 스킵인데도 O인 비율 |  |

→ 스킵인데 O가 많으면 **토큰 절약이 잘 되고 있는 것**.

## 목표 가이드

| 구간 | 해석 |
|------|------|
| 엄격 90%+ | 매우 좋음 (자동 확정에 가까움) |
| 엄격 75~89% | 실사용 가능, 사용자 확인 한 번이면 충분 |
| 엄격 60~74% | 지금 추정 구간. 규칙/후보 보강 여지 |
| 엄격 60% 미만 | 어려운 사진 비중 확인 + 틀린 패턴 정리 |
