기능 감사 반영 — 빠진 것 없이, 모드 시스템 완성

v3 모드 시스템(하늘·바다·노을)에 기능 감사에서 나온 보완 5건을 적용했습니다: ① 상태 대문 = 여행 전환기 · ② 상품 검색 복원 · ③ 커뮤니티 채널 삭제 · ④ 데이터 관리 → 프로필 · ⑤ 정렬 압축(일차순 기본 + 가격순 토글). 광고 2종과 선물 태그 3종(지인·동료·친구)은 기존 그대로 유지합니다. v5는 hallmark 스킬 감사를 통과한 판이며, 시스템 전체는 프로젝트 루트 DESIGN.md에 잠갔습니다 — 이후 모든 화면은 이 파일을 공유합니다.

탭 3개(홈·구경·프로필) + 컨텍스트 FAB. 하단 탭은 아이콘 온리 — 집=홈, 돋보기=구경, 사람=프로필. 활성은 색이 아니라 채워진 아이콘으로 표시해 파랑·라우시와 경쟁하지 않습니다. 보완 ①: 상태 대문의 노선(ICN ✈ NRT)을 탭하면 여행 전환 시트가 열립니다 — 내여행 탭이 사라진 자리를 대문이 대신합니다.

                      --mode-accent: #0d9488; }  /* 틸 — 블루·그린과 구분되는 hue */
[data-mode="after"] { --mode-canvas: #fff6e8;                    /* 노을 */
                      --mode-accent: #fb8500; }

   판정도 그 여행 기준으로 다시 칠해진다 */

// startDate ≤ today ≤ endDate → "live"
