# 디자인 시스템 가이드 (비개발자용)

이 문서는 **화면에 디자인을 어떻게 말해 주면 되는지**와, 현재 적용된 규칙을 정리한 것입니다.

## 브랜드

| 항목 | 내용 |
|------|------|
| 한글명 | 트립디토 |
| 영문명 | Trip Ditto |
| 의미 | DITTO + Trip — 복잡함 없이 여행 쇼핑 |
| 로고 | `/public/brand/logo.png` — 헤더·랜딩에서 텍스트 대체 |
| 심볼 | 캐리어 3D (`symbol.png`) — 앱 아이콘·파비콘 |

## 현재 적용된 방향

| 항목 | 내용 |
|------|------|
| 느낌 | 화이트 배경, 토스/오늘의집형 밀도, 세련됨 |
| 브랜드 컬러 | 액션 블루 `#3182F6` |
| 포인트 | `#FB8500` 오렌지 / `#FFB703` 앰버 |
| 회색 카드 | `GrayCard` (`#F2F4F6`) — 설명/안내용 추가 에셋 |
| 흰 카드 | 기존 `Card` 유지 |

## 반응형 (대중적 구간)

| 구간 | 너비 | 콘텐츠 최대폭 |
|------|------|----------------|
| 모바일 | 320 ~ 767px | 480px |
| 태블릿 | 768 ~ 1023px | 720px |
| 데스크톱 | 1024px+ | 960px |

## 다음에 디자인 요청할 때 이렇게 말하면 됩니다

```
1. 느낌: (예: 더 밝게 / 포인트 오렌지를 더 많이)
2. 바꿀 화면: (예: 홈만 / 쇼핑 리스트 / 전체)
3. 참고: (앱 이름 또는 캡처)
4. 꼭 지킬 것 / 싫어하는 것
```

적용 완료. 랜딩(`/`) → 메인(`/home`), 헤더에 로고 표시.
