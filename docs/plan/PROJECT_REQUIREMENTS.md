# Shopping List (PoC)

## 프로젝트 개요

여행 전 SNS, 블로그, 유튜브 등에서 저장한 상품 이미지(캡처, 사진)를 업로드하면 AI가 분석하여 쇼핑 리스트를 생성하는 웹 서비스 개발

사용자는 여행을 준비할 때 쇼핑 리스트를 쉽게 만들고, 여행 중에는 모바일에서 체크리스트처럼 사용할 수 있어야 한다.

본 프로젝트는 PoC(MVP)를 목표로 하며, AI 분석 기능은 이후 연동을 고려하여 구조를 설계한다.

---

# 목표

- 여행 전 쇼핑 준비 간소화
- 여행 중 쇼핑 경험 개선
- 이미지 기반 쇼핑 리스트 생성
- 모바일과 PC 모두 지원하는 반응형 웹 구현

---

# 기술 스택

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod
- TanStack Query

새 프로젝트로 시작한다.

기존 starter-web은 개발 환경 및 라이브러리 참고용 Seed 프로젝트이며, 소스 구조와 레이아웃은 그대로 사용하지 않는다.

서비스 특성에 맞게 처음부터 설계한다.

# 반응형

Mobile First

반응형 지원

- Mobile
- Tablet
- Desktop

PC에서는 여행 준비가 편해야 하며,

모바일에서는 앱처럼 사용하기 쉬운 UX를 제공한다.

---

# UX 방향

복잡한 관리 시스템이 아닌 Consumer Service를 목표로 한다.

빠르고 직관적인 UX

최소한의 클릭
